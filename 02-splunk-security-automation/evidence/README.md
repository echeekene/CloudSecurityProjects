## Publication Privacy

Screenshots containing password-like strings, contact details, personal browser/profile context, or internal network configuration are excluded. Redundant setup images and unrelated material are also omitted.

Lab hostnames, synthetic user names, the reserved .test domain, timestamps, localhost URLs, and loopback addresses remain where relevant to the results. No visible passwords, tokens, personal email addresses, or private network IP addresses were identified in the selected images.

Screenshot filenames and event timestamps are distinct. The filename alone does not establish a capture timezone.
